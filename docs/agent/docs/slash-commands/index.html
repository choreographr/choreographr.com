Slash commands

/agent/docs/slash-commands/

All commands in choreo-tui use the / prefix. Typing / on an empty prompt opens the command palette — Enter runs the highlighted command, Tab completes the name, ↑/↓ move the selection, and Esc returns to the prompt. The palette and the parser share one catalog, so what you see is what runs.

Sessions

CommandDescription
/new [title]Create a session and switch to it
/sessionOpen the session manager (or list, new [title], switch <id>, info <id>)
/undoUndo the most recent user turn and its entire assistant response subtree
/redoRedo the most recently undone turn
/continueContinue a stopped/idle session ("Please continue.")
/cancel <request-id>Cancel a request by id
/stopCancel whatever request is active on the attached session
/pingHealth check

In the session manager (Alt+S), Tab toggles between the live and archived lists, p pins or unpins a session (pinned sessions sort to the top), and a archives or unarchives one.

Models & accounts

CommandDescription
/model [model]Choose the session's model (opens the picker when omitted)
/accountOpen the accounts page (or list, remove <name>, <name> to set)
/refresh-models [--force]Refresh the models.dev catalog
/login <account> [--device]Sign in to an existing account's provider with OAuth (alias /add-oauth); --device selects the headless device-code flow

Alt+A opens the accounts page — list accounts, remove with r, set an API key with c, or start the new-account wizard with n.

Reasoning

CommandDescription
/reasoningCycle the reasoning effort
/reasoning listList the available reasoning levels
/reasoning <level>Set reasoning effort (e.g. off, low, medium, high, on, xhigh, max)

Access control

CommandDescription
/acl add <base64-pubkey>Enroll a client in the daemon's allow-list

Client allow-listing is stored in authorized_clients.toml and hot-reloaded from disk. See Security.

MCP servers

CommandDescription
/mcpShow every MCP server visible to the session (daemon + project tiers), with transport, auth state, connected state, tool count, or last error — plus the project root's trust state
/mcp reconnect <slug>Rebuild every connection with that slug on the running daemon and refresh its tools
/mcp reloadRe-read the config on the running daemon — connect added servers, drop removed ones, rebuild changed ones — without a restart
/mcp login <slug>Run a PKCE OAuth sign-in for a server that declares an oauth block; the grant is stored in the keystore and the server reconnects itself
/mcp logout <slug>Remove that server's stored OAuth grant
/mcp trustTrust the session's project MCP root so its servers connect
/mcp untrustRevoke trust for that root; its project servers stop
/mcp trust listList the trusted project roots

Offline management lives in the choreographr mcp CLI (list, add, remove, reconnect, reload). See the tools reference for how MCP servers are configured.

Credentials

CommandDescription
/add-key <service> <api_key>Store an API-key credential
/add-x <service> <key> <secret> <token> <token_secret> <bearer>Store an X/Twitter credential
/login <account>Sign in with OAuth instead of an API key (see models & accounts)
/remove-key <service>Remove a stored credential

Locking

CommandDescription
/unlock [base64-key]Unlock the daemon — uses the stored per-daemon key, or records key on an already-bound daemon
/lockLock the daemon, clearing credentials from memory

Client

CommandDescription
/quitExit the TUI

Any other input is sent to the attached session as a prompt. In choreo-tui, Ctrl+C exits the local client and disconnects from the daemon without requesting daemon shutdown.

Keyboard shortcuts

Command shortcuts use Alt+ — the Ctrl+<letter> space is reserved for readline editing keys.

ShortcutAction
Alt+AAccounts page
Alt+SSession manager
Alt+MModel selector
Alt+RCycle reasoning effort
Alt+HToggle the keybinding help overlay
Alt+Up / Alt+DownUndo / redo
Alt+EnterContinue
Alt+QQuit
