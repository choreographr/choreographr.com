AI Agent Training — Da Nang is a weekly two-hour, drop-in beginner class where
students build a custom website with an AI agent, without writing any code.

- Format: weekly, two hours, drop-in; maximum 10 people per class.
- Price: 400,000 VND per class, paid in cash or by banking QR.
- Venue and day/time: to be confirmed, central Da Nang, easy to reach by
  motorbike.
- Audience: beginners — no coding experience or prior knowledge required.
- What you learn: to describe a website in plain English to an agent
  (Choreographr), review what it builds, and refine it until it is yours —
  then deploy it live to GitHub Pages (free hosting, custom domains supported).
- The path: set up your workspace; chat with your agent to build your site;
  make it look good; keep changes safe with Git; deploy it live.
- Technologies used: Ghostty, Choreographr, Zola, daisyUI, Tailwind, Git,
  GitHub Pages.
- Skills transfer to any AI coding tool: Claude Code, Cursor, GitHub Copilot,
  OpenCode.
- Model access: OpenCode Go (https://opencode.ai/go?ref=K76T4060YH) from
  $5/month, or any provider Choreographr supports. Windows users use the
  OpenCode agent instead, as Choreographr does not yet support Windows.
- Instructor: Jonathan Brown, backend engineer with 30 years of experience
  building production systems, and the author of Choreographr.
- Signup: join the WhatsApp group at https://chat.whatsapp.com/BtVATGh7odDLpYbuXAtfZp.
