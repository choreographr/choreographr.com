The network's off-chain event indexer decodes the on-chain event stream and
serves it as a queryable, subscribable API — the layer that makes the content
graph readable by the wiki, feed, and any agent.

These docs were ported from the original Acuity Index project. Start with the
[problem](@/content/docs/indexer/problem.md) it solves and the
[solution](@/content/docs/indexer/solution.md).
