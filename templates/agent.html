{# ============================== WHAT IT IS / FEATURES ============================== #}

Everything in the box

🖥️

Server + multi-client

Sessions live in the server. Connect from a terminal, desktop app, Telegram, or an ACP-compatible editor.

🌳

Hierarchical subsessions

Break work into child sessions that run their own agent loop and report back. Pause, re-prompt, and nest them.

↩️

Undo / redo, per session

If an agent mis-steps, remove the prompt instead of prompting more. Multiple sessions run simultaneously.

🔑

Encrypted keystore

Credentials encrypted per-credential with X25519 ECDH + AES-256-GCM. The server starts locked.

🔐

Sandboxed RISC-V VM

LLM-generated code is compiled to RISC-V and executed in an isolated ckb-vm sandbox. A complete replacement for the shell tool — full control and observability.

🧠

200+ model providers

OpenAI-compatible, Anthropic Messages and Google Gemini — OpenAI, Anthropic, Mistral, DeepSeek, xAI, Groq, Ollama, OpenRouter and many more.

🖼️

Images in the terminal

The TUI renders PNG, JPEG, and vector SVG inline in your chat history — kitty graphics or sixel where supported, with a universal fallback everywhere else.

👁️

Vision input

Hand images to a vision-capable model — read a screenshot, a diagram, or a photo and have it reason about what's in the frame. SVG, HEIC, and EXIF orientation handled.

🌐

Bring your own browser

A local headless Chromium renders any URL — HTML, text, screenshot, or PDF — so JavaScript-heavy and bot-protected sites work. Runs locally and offline.

🔌

MCP client

Speaks the Model Context Protocol — spawn MCP subprocess servers, discover their tools, and call them from any session.

✏️

ACP bridge

Drive Choreographr sessions from ACP-compatible editors like Claude Code and Cline over JSON-RPC, right from your IDE.

💾

Agent databases

Persistent, session-scoped key-value stores the agent can write to and read back later. Survives restarts in the embedded redb database.

⛓️

Content blockchain

Publish content items, revisions, and profiles to the Choreographr Content blockchain as signed extrinsics, and query them back through its indexer — with native read-only Polkadot and EVM tools beside it.

🛡️

Noise-IK transport

Remote clients connect over an authenticated, encrypted Noise IK TCP transport with X25519 key agreement.

📊

Metrics & observability

An optional OpenMetrics endpoint for session counts, request latency, tool execution time, and process-level metrics.

{# ============================== CONTENT NETWORK (bridge) ============================== #}

Built-in access to the Content blockchain

The agent reads blockchains today. It can now publish directly to the Choreographr Content blockchain — so agents can research and then write their findings to an immutable, content-addressed, timestamped wiki that other agents and humans build on.

  • ▸ Publish content items and revisions as signed extrinsics
  • ▸ IPFS content-addressing with on-chain timestamps and ownership
  • ▸ Queryable via Acuity Index — read it back, build on it

{# ============================== ARCHITECTURE ============================== #}

Architecture at a glance

A small, high-performance core written in idiomatic Rust — OS threads, message passing, no async runtime — with everything else plugging in as clients, tools and providers.

{# ============================== SECURITY ============================== #}

Security is not an afterthought

Giving an LLM direct shell access is risky. Choreographr gives it a sandbox instead: generated code is compiled to RISC-V and executed in an isolated VM with a 4 MB flat memory space and a configurable cycle budget. Every tool access goes through the same registry as the host agent — no host memory, no raw syscalls, no escape hatch.

  • ▸ OS-level sandboxing (Landlock / Seatbelt) planned for tools run outside the VM
  • ▸ Credentials encrypted per-credential with X25519 ECDH + AES-256-GCM
  • ▸ Server starts locked — credentials decrypted only in memory after unlock
  • ▸ Remote connections use the Noise IK protocol with X25519 key agreement

{# ============================== ROADMAP ============================== #}

On the agent roadmap

Choreographr is under active development. A taste of what's planned for the agent:

🔁 Inter-server handoff

Pass sessions between daemons over Noise-IK so work can be deployed or continued elsewhere.

🧩 Extensions

Hook into the server over a local socket to expose new tools and plugins.

⏰ Cron

Run programs automatically at designated times.

🌿 Git worktree support

Parallel subsessions on their own branches with CoW filesystems to avoid rebuilding gigabytes of artifacts.

🔄 Looping

Automate the "review → fix → review" loop until a goal is met, unattended.

🖥️ OS-level sandboxing

Landlock on Linux, Seatbelt on macOS — for tools that must run outside the VM.
